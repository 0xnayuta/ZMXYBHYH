# 造梦西游八荒 / 八荒湮隳 逆向工程与工程资产仓库

本仓库用于整理与研究《八荒湮隳》及衍生版本（包括造梦青川版）的客户端架构、资源格式、解密方案与源码重构。

## 三、工具链与流水线使用指南

### 1. 还原 1.2.0.1 缺失的真实资产
```bash
python tools/recover_v1.2_assets.py
```

### 2. 解包 1.3.3.2 并正位构建纯净源码工程
```bash
python tools/reconstruct_1.3.3.2_to_source.py
```

### 3. 解包 6.5.0.0 并正位反编译源码工程
```bash
# 步骤 1: 全量解密 PCK 提取到 extracted/6.5.0.0/
python tools/zmbh_decrypt.py --out extracted/6.5.0.0

# 步骤 2: 反编译 874 个 .gdc 为 .gd，还原 1.6 万+ 贴图到 source/v6.5.0.0/
python tools/reconstruct_6.5.0.0_to_source.py
```
